# Sprint Rules

Sprint Duration

1–2 Weeks

Sprint Goal

One working milestone.

Definition of Done

- Code Complete
- Build Passes
- Tests Pass
- Documentation Updated
- Git Commit Created
- Human Review Completed

Never start the next sprint until the current sprint is complete.
